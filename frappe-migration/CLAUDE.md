# CLAUDE.md

`tll_crm` is a Frappe app: a CRM for a small Thai law and visa services firm, with a work log built into it and light finance attached. It replaces a customised Twenty CRM workspace.

## Read first

- `docs/00-BRIEF.md` — what the system is, the constraints, and the platform decisions already made. Read this before proposing anything.
- `docs/02-FRAPPE-PLAN.md` — app shape, client model, timeline design, type mapping, build order.
- `docs/01-DATA-MODEL.md` — the full Twenty data model this is rebuilt from. Reference, not a spec to copy literally.
- `docs/schema.json` — the same data model, machine-readable.

## Decisions already made, do not reopen

These were argued through. Raise one only if you find a concrete problem, not a preference.

- **Custom app on the bare Frappe framework.** ERPNext is not installed and was rejected on purpose. Frappe CRM and BottleCRM were rejected too. The reasoning and the reversal conditions are in the brief.
- **The doctype is `Job`, not Matter or Case.** Twenty's `opportunity` and its `matter` link fields both mean `Job`.
- **`Client` is one doctype** with a `client_type` of INDIVIDUAL or ORGANIZATION. Do not split it into person and company the way Twenty does.
- **Frappe's stock `Contact`** holds the humans, linked to Client. `contact_identity` links to Contact, never to Client, and never via a Dynamic Link.
- **FlowAccount is the ledger.** Nothing here posts an accounting entry.
- **The client page is the point of the system.** Anything that makes the client record less complete is the wrong trade.

## The test the system has to pass

Open a client and see everything: who they are, every job run for them, and one merged timeline of what happened. `Timeline Entry` exists for this and is described in the plan.

## Conventions

- Follow the build order in the plan. Steps are ordered so each one is verifiable before the next.
- Doctype names in Title Case, fieldnames in snake_case. No abbreviations.
- Money is Currency in THB. Twenty stores integer micros; do not carry that over.
- Work logs are stored in minutes. Any hours figure is display only.
- Never delete a numbered document. Cancel it and keep the number.
- `Timeline Entry` is a projection, never a source of truth, and is only ever written by the shared helper.
- UI in English, content in Thai. Names get parallel English and Thai fields; free text is just Thai.
- Print formats need a Thai font (Sarabun or Noto Sans Thai). Prove a Thai string renders in a real PDF before building a print format on top of it.

## Commands

```bash
bench start                                  # dev server, from the bench root
bench --site tll.localhost migrate           # after any doctype change
bench --site tll.localhost console           # python repl against the site
bench --site tll.localhost mariadb           # sql shell
bench build                                  # frontend assets
bench --site tll.localhost run-tests --app tll_crm
bench --site tll.localhost export-fixtures   # after changing custom fields
```

Doctype JSON is generated by the UI and committed. Create doctypes in Desk at `/app/doctype`, then commit the resulting files, rather than hand-writing the JSON.
